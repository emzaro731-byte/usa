# Business With The USA Website

Responsive static website for Business With The USA.

## Files
- `index.html` — complete website homepage
- `styles.css` — responsive styling
- `script.js` — navigation and demo enquiry form

## Publishing
Enable GitHub Pages from repository Settings → Pages and select the `main` branch as the source.

Before launch, verify the business contact details and connect the enquiry form to a real email, CRM or backend.

The supplied Google Maps short link is included in the Contact section.
